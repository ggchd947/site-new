The Newtonian Mastery Algorithm

Introduction

This is the algorithm Newton used to read van Schooten’s two volume book. He read a few pages or so, couldn’t understand the text, and went back to the beginning. Went a little further then stopped again going back to the beginning. He repeats this loop by himself until he finally ‘makes himself whole of Descartes’.

The Method

1. RECON

Scan the chapter. Note the structure: definitions, theorems, oral exercises, written exercises. Identify the core concepts.

2. THE DEEP READING & NOTE-TAKING LOOP (For Each Section)

For each DEFINITION:

  • Write it verbatim, then immediately rephrase it in your own words below.
[Notebook Entry]
Def: [Copy verbatim]
My take: [Rephrase in your words]
Ex: [Create 1 example]
Non-Ex: [Create 1 counterexample]

For each THEOREM/LEMMA:

[Notebook Entry]
Thm: [Statement with label, e.g., "Them 2-3"]
Why: [Guess its purpose - how will it be used?]
Attempt: [Proof attempt on scratch paper - 5-15 min]
Gap: [After comparing, note what you missed]

For each EXAMPLE:

  • Don’t copy the example’s solution. Write the principle it demonstrates.
[Notebook Entry]
Example (p.X): [Brief description]
Principle: [Core idea demonstrated]

3. THE FLUENCY DRILL (Oral Exercises)

  1. Mental Solve: Read each problem, solve it in your head within 3 seconds.
  2. Self-Check: Verbally state the answer and the one-sentence rule/definition that justifies it (e.g., “False, because 5 ∉ {-5}”).
  3. Log (If Needed): Use a “One-Liner Log”, only write the problem number, final answer & core justification. Do not write out steps.
  4. Diagnose: Any hesitation or error triggers an IMMEDIATE RESET to re-read the relevant text.

4. THE MASTERY BUILD (Written Exercises)

  • Full Written Work: Solve Set A, B and C completely
  • Annotate Solutions: Justify key steps with Def/Thm/Axiom (Example: “by distributive property,” “by Thm 1-2,” etc.)
  • Stuck >10 min?: Diagnose weak concept, return to Phase 2 for that concept only

5. THE RESET DECISION

  • If you struggle significantly with the Oral Exercises: Reset the entire section.
  • If you struggle with a Written Exercise: Diagnose the faulty concept and reset only the relevant part of the section or a prior section.
  • If you pass both Oral and Written fluently: Proceed to the next section.
